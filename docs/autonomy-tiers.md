# 自律度の段階

AI にどこまで任せるかを3段階で捉える。いまは**段階2**を上限として運用する。

| 段階                   | 何をするか                                                             |
| ---------------------- | ---------------------------------------------------------------------- |
| 段階1: 報告だけ        | 状況を仕分け（優先度づけ）してメモに残す。コードは変えない。           |
| **段階2: 補助**（いまここ） | 作る役とチェックする役を分けて修正。本体への取り込み・公開は人が判断。 |
| 段階3: 無人            | 禁止事項以外を自動。予算・計測・禁止リストを整えてから検討する。       |

## 暴走を防ぐ仕組み

- **作る役とチェックする役を分ける** — 自分で作って自分で合格を出すと甘くなるため、別の役が点検する。テスト結果の提示を必須にし「やった体」の偽装を防ぐ。
- **止めどきを最初に決める** — 目標達成／人へ引き継ぎ／試行回数の上限／予算超過。
- **使う費用に上限** — 軽い作業は任せず直接やる（費用と見えやすさのバランス）。
- **中身の理解を置き去りにしない** — 節目ごとに要約と読み直しを行い、AI に作業量を渡すのでなく「判断」を渡す。
- **同時作業の衝突を防ぐ** — 作業用の別コピー（worktree）に分けて進める。

段階2 の中核である「作る役 ≠ チェックする役」は、規律 C として [`.kiro/steering/orchestration.md`](../.kiro/steering/orchestration.md) に正本がある。
