# デザインブリーフ：開発ダッシュボードのビジュアルリファイン

## これは何か

AIエージェント主体の開発プロジェクトにおける**進捗ダッシュボード**（1ページの静的HTML）です。プロダクトオーナー・統括（コンダクター）・レビュアーが日常的に確認する画面で、見積もり・作業ボード（カンバン）・節目・機能ごとの状態・健全性KPI・運用パネル・体制図（組織図・Mermaidフローチャート）・更新履歴などを1枚に集約しています。

- **閲覧方法**：ローカルファイルをブラウザで直接開く（`file://`）ことが前提。稀に簡易ホスティングされることもある。**外部ネットワーク接続なしで完全に表示できる必要がある**（フォント・アイコン・図を含め、CDN依存は不可）。
- **技術構成**：Astro（`.astro`コンポーネント）＋ Tailwind CSS v3（ビルド時コンパイル）＋ Mermaid.js（組織図・フローチャートをクライアントサイド描画）。
- **成果物としてほしい形**：**新しいTailwindトークン値（色・タイポ・角丸・影）＋主要コンポーネント（カード・バッジ・KPI統計・カンバンカード）のスタイル定義**。既存の `.card`／`.badge`／`.kpi` 等のCSSコンポーネントクラスをそのまま置き換えられる形が理想です。

## 改善してほしい3つの方向性

### 1. 視覚的な洗練さ・モダンさ

現状は暖色ベージュ系の単色カードUIで、影・角丸・余白は統一されているものの**全体が単調**です（すべてのカードがほぼ同じ視覚的重みを持ち、「主役」がない）。もっと洗練された、モダンな印象に更新してください。

### 2. 情報の見やすさ（階層・視線誘導）

セクションが縦に多く並びます（見積もり／作業ボード／節目／機能ごとの状態／健全性KPI／運用パネル／次アクション／更新履歴）。文字サイズがほぼ全て11〜14px程度に収束しており、**「今すぐ見るべきもの」と「参照用の詳細」の視覚的な差が弱い**のが課題です。また、作業ボードのカンバンカードは彩度の低い同系色で並び、レーン（デザイン系／エンジニアリング系）の区別が背景色のわずかな違いのみに頼っています。タイポグラフィのスケール（サイズ・太さのメリハリ）と、重要度に応じた視覚的な強弱をつけてください。

### 3. ダークモード対応

現状はライトテーマのみのハードコード値です。**ライト／ダーク両方のトークンセット**を提案してください。トグルUIは不要です（OSの `prefers-color-scheme` に自動追随する設計を想定しているため、JS実装が不要な形が望ましい）。

## 配色について

現状のベージュ・ブラウン系（accent = #b08968）に縛られる必要はありません。**新しい配色を自由に提案してください**（ライト／ダークそれぞれ）。

---

## 変えてはいけない制約

- **Mermaid図とのトーン整合**：組織図・フェーズ別ツリー図（6種）・外部サービス関係図・PDCA循環図はすべてMermaidで描画されています。Mermaidは `mermaid.initialize({ theme, themeVariables })` でテーマ変更が可能なので、提案する配色はこれらの図にも展開できる形（セマンティックなトークンとして）でお願いします。
- **日本語の可読性**を落とさないこと（Noto Sans JP等での視認性）。
- **情報量を削らないこと**：レイアウトや階層表現の強化はOKですが、表示している内容そのものを省略しないでください。
- **オフライン動作**：外部CDN・Webフォント等への新規依存を増やさないこと。

---

## 受理条件（このデザインが満たすべき基準）

- コントラスト比 WCAG AA 準拠（本文4.5:1以上・UI部品3:1以上）
- 状態の網羅：hover／focus／disabled／error／empty／loading の各状態
- 色・余白・タイポはすべてトークン経由（直書きの値を残さない）
